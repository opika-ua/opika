# Commissioner (self-hosted)

- **Files:** both unmodified, copied byte for byte from the upstream repository at commit
  `7f7dc8e9ed7ffeb3f7a91261f2b9549436ab3d02`:
  - `Commissioner-Regular.woff2` (65,984 bytes, SHA-256
    `4a67df4e771687f2305adb9217e0d51af86311407f585938c766e359500a6c28`), upstream path
    `fonts/webfonts/Commissioner-Regular.woff2`.
  - `Commissioner-Medium.woff2` (66,236 bytes, SHA-256
    `838c2019b415ebdf8dc469734d25321abf59aee798ea4edf95a79c967fef2be8`), upstream path
    `fonts/webfonts/Commissioner-Medium.woff2`.
- **Source:** the designer's repository, <https://github.com/kosbarts/Commissioner> (Kostas
  Bartsokas). Commit
  [`7f7dc8e`](https://github.com/kosbarts/Commissioner/tree/7f7dc8e9ed7ffeb3f7a91261f2b9549436ab3d02)
  (2023-02-01, "Merge pull request #47 from RosaWagner/googlefonts") is the commit Google Fonts
  packaged: `google/fonts`' `ofl/commissioner/METADATA.pb` names it as its source. That
  `METADATA.pb` cites it through the `m4rc1e/Commissioner` fork, and the commit is on the
  upstream `master` too. It is not a tagged release. Upstream's releases are 1.000 (2020) and
  1.012 (2025). Google Fonts serves neither; it serves this commit's build. Font version string:
  `Version 1.001; ttfautohint (v1.8.4.7-5d5b)`. Google Fonts served the build
  `Version 1.001;gftools[0.9.23]`.
- **Which family:** the plain `Commissioner` (the Flair and Loud families in the same folder
  are not used). Google serves this one, at its default `FLAR`/`VOLM` (0) and upright `slnt`
  (0). Those are the defaults these static instances carry.
- **Licence:** SIL Open Font License 1.1. `OFL.txt` here is a verbatim copy of
  <https://github.com/kosbarts/Commissioner/blob/7f7dc8e9ed7ffeb3f7a91261f2b9549436ab3d02/OFL.txt>
  (4,395 bytes, SHA-256 `4a7d88c77b4bc39ff84f2e058ba8f015636c50ce33588a86d9da97defe519933`). It is
  identical to upstream `master`'s and to `google/fonts`' `ofl/commissioner/OFL.txt`. Its
  copyright line ("Copyright 2019 The Commissioner Project Authors") declares no Reserved Font
  Name. The OFL allows the font to be bundled and redistributed with software as long as the
  licence travels with it (condition 2), and these files are unmodified anyway.
- **Why only Regular and Medium:** see the comment on `commissioner` in `../../fonts.ts`.
