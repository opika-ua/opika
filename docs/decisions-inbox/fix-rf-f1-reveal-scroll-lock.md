| RF-F1-D1 | 2026-10-20 | `RevealFlow.test.tsx:325` ("Escape closes the dialog, restores focus to the trigger, and unlocks page scroll") failed once in CI (expected `'hidden'`, got `''`); the rerun passed | Is the race a real product defect (the page is briefly scrollable behind an open dialog) or a test-only artifact, and which fix follows | `waitFor` around the assertion (test only, tolerates the race) · switch the scroll-lock effect from `useEffect` to `useLayoutEffect` (app code, removes the race) | `useLayoutEffect`. Confirmed by forcing it deterministically: a `MutationObserver` reading `document.body.style.overflow` at the instant the `reveal-dialog` node first appears in the DOM saw `""` under the passive `useEffect` and `"hidden"` under `useLayoutEffect`, for the same render. This dialog mounts only after an awaited `animals.reveal` resolves, not inline inside the click that triggered it, so its passive effect was scheduled for after the browser's next paint rather than flushed before it — a real, if usually brief, frame where the overlay is visible and the page behind it can still scroll, in a real browser as well as the test. A layout effect runs synchronously in the same commit that inserts the dialog, before anything paints, so that frame never exists at all. This is a strictly better fix than `waitFor`: it removes the underlying race rather than giving the test more patience with it. The fix landed with a new regression test built from the same `MutationObserver` probe (committed in the review-notes follow-up, not the first commit): the first commit's forcing run showed the old assertion passing 50/50 across three runs with the lock reverted to a passive effect — proof the plain `toBe("hidden")` check right after `findByTestId` cannot reliably catch this regression on its own, which is exactly why the probe itself needed to become a test rather than stay a one-off diagnostic. | — | fixed in this branch; see `apps/web/src/features/reveal/ContactRevealDialog.tsx` and the new test in `apps/web/src/features/animal-detail/RevealFlow.test.tsx` |
