   `Array.from(rows as Iterable)`.
   - Failure scenario: on neon-http, drizzle-orm 0.45.2 `neon-http/session.js` runs raw SQL with
     `rawQueryConfig = { arrayMode: false, fullResults: true }`, which returns `{ rows, fields, … }`.
     That object is not iterable, so `Array.from` gives `[]`. Every count is then 0 and production
     no-match screens offer no relaxation.
   - Why it matters here: DR1-D11's premise is that "the relaxation count says how many", and fur
     now flows through this path. It is the same class as the `hasActiveSeenSet` incident in the
     standing constraints. `client.ts` says nothing in `repos/` calls `.execute()`, and that claim is
     false.

     on main by cb88c11 (#112). `neon-smoke.ts` doesn't exercise it.
