# Radio

File: `apps/web/src/ui/form.tsx`

**Purpose.** One option of a radio group; the whole row is the target.

**Props and variants.** `label` plus input attributes.

**Accessibility.** Group them in a `fieldset` with a `legend`.

**Responsive.** 48px rows.

**Example.**

```tsx
<Radio name="r" label="Так" />
```
