# MenuDivider

File: `apps/web/src/ui/Menu.tsx`

**Purpose.** A thin rule between groups of a Menu's entries (the safe moves, then the destructive one).

**Props and variants.** None.

**Accessibility.** A decorative `li` (`aria-hidden`); not focusable.

**Responsive.** Full width of the panel.

**Example.** `<MenuDivider />` between two `MenuItem`s.
