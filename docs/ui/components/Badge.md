# Badge

File: `apps/web/src/ui/Badge.tsx`

**Purpose.** A small tag that sits on a photo.

**Props and variants.** `tone`: dog, cat, ink, neutral. No warning tone: freshness is never red or amber.

**Accessibility.** Text only; state is in the words.

**Responsive.** Content-sized.

**Example.**

```tsx
<Badge tone="dog">Оновлено сьогодні</Badge>
```
