# PrevNext

File: `apps/web/src/ui/PrevNext.tsx`

**Purpose.** Previous and next as icon links.

**Props and variants.** `prev`, `next`: {href, label} or null.

**Accessibility.** Real links named by `label`.

**Responsive.** Two 48px circles.

**Example.**

```tsx
<PrevNext prev={{ href, label }} next={null} />
```
