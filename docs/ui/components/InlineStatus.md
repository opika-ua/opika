# InlineStatus

File: `apps/web/src/ui/feedback.tsx`

**Purpose.** A short message beside the thing it concerns.

**Props and variants.** `tone`: info, success, warning, error.

**Accessibility.** `role=status`, or `alert` for error.

**Responsive.** Full width.

**Example.**

```tsx
<InlineStatus tone="success">Збережено</InlineStatus>
```
