# Text

File: `apps/web/src/ui/Text.tsx`

**Purpose.** Body copy.

**Props and variants.** `look`: body (16), lead (20), hint (14, ink-2), label (16 / 600). `as`: p, span, div.

**Accessibility.** Hint stays ink-2 (AA); never lighter.

**Responsive.** No size below 14px.

**Example.**

```tsx
<Text look="hint">Оновлено 2 дні тому</Text>
```
